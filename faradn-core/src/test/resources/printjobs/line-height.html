LINE-HEIGHT

Default: this paragraph is long enough to wrap onto several lines, so the gaps between lines print at the printer's default spacing.

Tight (1.0): this paragraph is long enough to wrap onto several lines, so you can see the lines pulled close together.

Loose (2.0): this paragraph is long enough to wrap onto several lines, so you can see the extra space between each line.

Fixed 40px: this paragraph wraps onto several lines with a fixed 40-dot gap between them, independent of the font size.
